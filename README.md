Customer Churn Analysis

Customer churn analysis dashboard built using Power BI to analyze customer retention, churn rates, demographics, contract types, payment methods, geographic trends, and internet services.

Key Features
Customer churn rate and KPI analysis
Demographic and age-group analysis
Geographic churn comparison
Payment method and contract analysis
Internet service churn analysis
Churn category distribution
Data-driven customer retention recommendations
Key Insights
Overall churn rate: 26.99%
Total customers: 77,016
Total churned customers: 20,784
New joiners: 4,932
Highest displayed churn rate by contract: Month-to-Month (46.53%)
Highest displayed churn rate by internet type: Fiber Optic (58.33%)
Highest displayed state churn rate: Jammu & Kashmir (57.19%)
